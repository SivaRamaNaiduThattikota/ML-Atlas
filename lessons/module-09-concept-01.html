PROGRESSIVE BEGINNER CORE

More layers is not automatically more power

Before this module reaches for an actual nonlinearity, it has to close off the tempting shortcut: just stack linear units and call it a network. This lesson shows, concretely and then generally, why that shortcut buys nothing.

BEGINNER LESSON · 10 STEPS 01 Concept first 02 Why it exists 03 Concrete example 04 Technical mechanism 05 Architecture / flow 06 Important distinctions 07 Common mistakes 08 Project mapping 09 Readiness check 10 Next lesson
01 · CONCEPT FIRST

A network of linear units is still exactly one linear model

Take a hidden layer of linear units (a weighted sum plus bias -- no activation) and feed its outputs into a further linear output unit. Algebraically, that composition is itself just one weighted sum plus bias. Stacking linear layers, with nothing nonlinear between them, does not add expressive power -- it just relabels the same affine map with more parameters.

First memory: Two linear layers back to back always collapse into one. The "network" part of a neural network only starts doing real work once a nonlinearity sits between the layers.
02 · WHY IT EXISTS

Setting up the exact gap Module 09 exists to close

Module 09 is about to introduce activation functions, the perceptron's step function, and eventually backpropagation. None of that matters unless the "plain stacking" alternative is ruled out first, plainly and by construction. This concept builds and collapses a linear network so that Concept 02's step function, and every activation this module introduces after it, has a concrete, node-verified baseline to actually improve on.

03 · CONCRETE EXAMPLE

Decomposing Module 08 Concept 12's own fitted weights across two hidden units

Module 08 Concept 12 fit w0=-2.0, w1=0.8, w2=-0.02, w3=1.2 on the module's shared 8-row CFPB relief table (rows A-H: x1=prior_contact_attempts, x2=case_age_days, x3=timely_response, y=relief). This concept engineers a 2-unit linear hidden layer -- H1 carrying x1 and x2, H2 carrying x3 -- specifically so that recombining H1 and H2 in a linear output unit reproduces those exact four numbers.

04 · TECHNICAL MECHANISM

A "layer" here means weighted sum plus bias -- nothing else

Each hidden unit computes z_k = ∑_j W_kj x_j + b_k, exactly logistic regression's own linear core, just run twice with different weights. Feed both z_k values into a further linear output unit and the whole two-layer composition reduces to one affine map: w_eff = e·W_hidden, b_eff = e·b_hidden + b_out, where e is the output layer's own weight vector over the hidden units.

06 · IMPORTANT DISTINCTIONS

"More layers" and "more capacity" are not the same claim

Adding a hidden layer only increases what a network can represent once a nonlinearity sits between that hidden layer and whatever consumes its output. Without one, every additional linear layer is capacity in name only -- it can always be collapsed back down to the same single affine map it started as. Concept 02 (the perceptron's step function) and Concept 04 (activation functions generally) are where that actually changes.

07 · COMMON MISTAKES

"More units in the hidden layer must mean more power"

"A hidden layer with more units than the output layer must be doing something a single line can't."

False, node-verified at hidden widths 2, 3, and 5: the two-layer forward pass always exactly equals a collapsed single linear map, regardless of how many hidden units sit in between.

"If the collapsed weights match, the network must have learned the decomposition."

Backwards -- nothing was learned here. The hidden layer's weights were engineered, by hand, specifically to reproduce Module 08 Concept 12's already-fitted weights. That's the whole point: it's a proof by construction, not a training run.

MATHEMATICS

Definition of a layer, for this concept's purposes

z_k = ∑_j W_kj x_j + b_k

A layer, here, is a set of linear units: each one a weighted sum of the layer's inputs plus its own bias, and nothing else -- no sigmoid, no step, no ReLU, no activation of any kind sits on top of z_k. That absence of an activation is the entire subject of this concept.

DIAGNOSIS

The floating-point caveat, on row B specifically

zLog=0.4 vs zNet=0.40000000000000013 -- not a bug, and not the miss's cause.Computing row B's z directly (w0 + w1x1 + w2x2 + w3x3) gives exactly 0.4. Computing it through the network's own two-step path (H1, H2, then e1·H1 + e2·H2) gives 0.40000000000000013 -- a difference of about 1.1102230246251565×10−16, ordinary floating-point non-associativity from summing the same quantities in a different order. Both values round to the identical probability, p=0.5986876601. Row B's miss is a property of the decision boundary, not of this rounding noise.

12
MATHEMATICS

Why this must be true, algebraically

A hidden layer with no activation computes h = W1x + b1, an affine map. Feeding h into a linear output unit computes z = W2h + b2 = W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2). That is itself of the form Wx + b, with W = W2W1 and b = W2b1 + b2 -- one affine map, exactly as this concept's own w_eff/b_eff computed in Section 08. Composing any number of purely linear layers, at any width, always reduces the same way: the product of the weight matrices, and a bias built from the same composition.

13
CONTRAST

Contrast with sklearn's own MLP formula

A standard two-layer network's forward pass is usually written f(x) = W2·g(W1ᵀx + b1) + b2, where g is a nonlinear activation function such as ReLU or the logistic sigmoid. Delete g -- replace it with the identity function -- and the formula becomes exactly f(x) = W2(W1ᵀx + b1) + b2, the same composition Section 12 just proved collapses to one affine map. The activation function g is the entire difference between "this collapses" and "this doesn't."

14
CONTRAST

Contrast with Goodfellow, Bengio, and Courville

Paraphrasing rather than quoting directly (no source text was independently re-verified this pass): Deep Learning's chapter on deep feedforward networks uses the XOR function as its canonical example of a target that no purely linear model -- single-layer or stacked -- can represent, and uses that example specifically to motivate the need for a nonlinear hidden-layer activation. This concept's own collapse proof is the mechanical reason that example works: without an activation, a "deep" linear network is never anything more than the one linear model it started as.

CAREER PRACTICE

Interview questions

Conceptual: why does stacking linear layers not increase a model's representational capacity?
Because a linear layer computes an affine map (Wx+b), and the composition of any number of affine maps is itself one affine map -- W = product of the layer weight matrices, b built the same way. Without a nonlinearity between layers, a "deep" linear network is mathematically indistinguishable from one linear layer with different weights, as this concept's own w_eff/b_eff computation shows exactly.
Conceptual: what's the difference between "engineering" a decomposition and "training" one?
This concept's H1 and H2 were chosen by hand, working backward from Module 08 Concept 12's already-fitted weights, specifically so the collapse would reproduce them. Training would instead start from random or zero weights and adjust them from data via a loss function and an update rule -- nothing in this concept does that; it's a proof by construction, not a learning result.
Practical: if a two-layer linear network and a single logistic regression produce identical predictions, why build the two-layer version at all?
On its own, there's no reason to -- this concept's whole point is that you shouldn't, unless an activation function sits between the layers. The two-layer version only becomes worth building once Concept 02's step function, or a later concept's smoother activation, breaks the collapse and lets the network represent something a single line cannot.
